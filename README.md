# StudySync

StudySync is a modern student productivity dashboard designed to help students stay organized, manage their academic tasks, and improve productivity through an intuitive and interactive interface.

## Features

- 🔐 User Authentication
- 📋 Task Management
- 📌 Dynamic Kanban Board
- ⏱️ Pomodoro Timer
- 📝 Notes
- 📊 Productivity Analytics
- 📅 Calendar
- 🌙 Dark Mode
- 💾 Local Storage Support

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Chart.js
- Local Storage

## Future Enhancements

- Backend Integration
- Cloud Synchronization
- AI Study Assistant
- Reminder Notifications
